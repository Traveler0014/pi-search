### [tools/pi-search](./tools/pi-search)

Web search and page extraction for the pi coding agent, powered by the Tavily API.

**Commands:**

- `/search` — Quick web search via Tavily — /search <query>
- `/search-key` — Set, show, or clear the Tavily API key
- `/search-test` — Self-check: key/config plus an optional live API call

**Tools:**

- `search_web` — Search the web through Tavily and return ranked results with titles, URLs, and content snippets. Use for current events, facts that may have changed, or when the user explicitly asks to search/look something up online. Supports general, news, and finance topics plus domain filters.
- `search_extract` — Extract the full readable content of one or more web pages through Tavily. Use after search_web when snippets are insufficient, or when the user provides URLs and asks to read/summarize them.
