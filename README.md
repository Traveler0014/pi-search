### [tools/pi-search](./tools/pi-search)

Web search and page extraction for the pi coding agent, powered by pluggable search backends (Tavily and DeepSeek today).

**Commands:**

- `/search` — Quick web search — /search <query>
- `/search-config` — Open the settings menu (provider keys, default backend)
- `/search-test` — Self-check every backend, optionally with one live call each

**Tools:**

- `search_web` — Search the web through a search backend and return ranked results with titles, URLs, and text. Use for current events, facts that may have changed, or when the user explicitly asks to search/look something up online. Supports recency windows, domain filters, language preference, and three levels of per-result text.
- `search_extract` — Extract the full readable content of one or more web pages through a search backend. Use after search_web when the result text is insufficient, or when the user provides URLs and asks to read/summarize them.
